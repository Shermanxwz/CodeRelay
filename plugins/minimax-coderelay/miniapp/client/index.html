正在检查
请在 MiniMax Code 3.1.6 或更高版本的本地项目会话内打开本插件。普通浏览器无法调用桌面 Agent。

设备连接

输入 CodeRelay 服务地址和管理员生成的一次性配对码。

暂停接单会保留正在执行的任务。关闭插件或退出 MiniMax Code 会中断任务。重启后需重新点击“开始接单”。

项目

在目标项目会话内点击绑定。CodeRelay 会创建专用工作会话，继承项目目录，不接管原有聊天。

任务与审批

需要授权时在此选择，或打开 MiniMax 工作会话处理。未知结果不会自动重跑。

尚未收到任务

本地验证命令

仅执行你在此配置的程序和参数；远程任务无法替换命令。验证会在项目目录运行。

使用 shell:false。Windows 的 npm.cmd 无法直接执行；请使用 node.exe 加 npm-cli.js 的实际路径，或配置直接可执行的测试程序。命令输出会随任务回传，请勿输出凭据。
